
# Campus Service

## Project Goal
Campus Service is a small JavaScript project developed to demonstrate basic software development, version control, automated testing, and DevOps practices.

The project includes a simple addition function and automated unit tests.

## How to Run the Tests
1. Install Node.js.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

npm test

- JavaScript
- Node.js
